# VAK_4.94_bhasya

## Kārikā

**apraheyasya te tv ekaṃ dve catvāri yathākramam |**  
**ayogavihitaṃ kliṣṭaṃ vidhibhraṣṭaṃ ca kecana || 4.94 ||**

> For non-abandonable karma, those [three classes of result-dharmas] are respectively one, two, and four. Some hold that improperly constituted action is afflicted action, and also action that has fallen away from proper procedure.

[Kārikā study](./VAK_4.94.md)

---

## Bhāṣya Source

The first half completes the matrix begun in 4.93:

```text
apraheyasya karmaṇo darśanaheyā dharmā ekam adhipatiphalam /
bhāvanāheyā dve puruṣakārādhipatiphale /
apraheyāś catvāri vipākaphalaṃ muktvā /

punar yathākramagrahaṇam ādyantavan madhye 'pi jñāpanārtham /
eṣa hi peyāladharmaḥ /
```

The Bhāṣya then opens a new question:

```text
karmanirdeśaprasaṅgenedam api paripraśnyate /
śāstreṣu ayogavihitaṃ yogavihitaṃ,
naivayogavihitaṃ nāyogavihitaṃ ca karmoktam /
tasya kiṃ lakṣaṇam /
```

and comments on the second half of the verse:

```text
kliṣṭaṃ karmāyogavihitam ayoniśomanaskārasaṃbhūtatvād ity eke /

vidhibhraṣṭam apīty apare /
yena yathā gantavyaṃ sthātavyaṃ bhoktavyaṃ pravicaritavyam ity evamādi /
tac cānyathā vidadhāti /
tad ayuktavidhānād ayogavihitam iti /

kuśalaṃ karma yogavihitam avidhibhraṣṭaṃ cety apare /
ubhābhyām anyan nobhayathā /
naivayogavihitaṃ nāyogavihitam /
```

---

## Natural Segmentation

This verse contains two distinct argumentative units.

### A. Completion of the abandonment-status fruit matrix

For **apraheya** karma, results classified as:

1. `darśana-heya`
2. `bhāvanā-heya`
3. `apraheya`

stand in respectively:

```text
1 / 2 / 4
```

technical fruit-relations.

### B. Classification of action by proper or improper constitution

The text then asks about three classes already found in the śāstras:

```text
ayogavihita
    improperly constituted / improperly applied

yogavihita
    properly constituted / properly applied

naiva-yogavihita-na-ayogavihita
    neither properly nor improperly constituted
```

The Bhāṣya reports more than one definition of `ayogavihita`.

---

## Literal Prose Translation

For karma that is not to be abandoned, dharmas abandonable through seeing are one result, namely the dominant result. Dharmas abandonable through cultivation are two results, the activity-produced and dominant results. Dharmas that are not to be abandoned are four results, all except maturation.

The word `yathākramam`, “respectively,” is stated again so that the ordered correspondence should be understood in the middle case just as at the beginning and end. This is a matter of abbreviated recitation (`peyāla`).

In connection with the exposition of karma another question is asked. The treatises speak of action that is improperly constituted, properly constituted, and neither properly nor improperly constituted. What are their characteristics?

Some say that afflicted karma is `ayogavihita`, because it arises from improper attention (`ayoniśomanaskāra`). Others say that action which has deviated from the proper procedure is also `ayogavihita`: for example, when there is an appropriate way to go, stand, eat, move about, and so forth, but one performs these otherwise. Because its procedure is unsuitable, it is called improperly constituted.

Others say that wholesome karma is `yogavihita`, and also action that has not deviated from the proper procedure. What is other than both of these is neither properly nor improperly constituted.

---

## Argument Reconstruction

### 1. The apraheya row

The Bhāṣya completes the 3 × 3 abandonment-status matrix:

| Source karma ↓ / Result dharma → | darśana-heya | bhāvanā-heya | apraheya |
|---|---|---|---|
| darśana-heya | 3 | 4 | 1 |
| bhāvanā-heya | 2 | 4 | 3 |
| **apraheya** | **1** | **2** | **4** |

The exact memberships for the third row are:

```text
apraheya → darśana-heya
    adhipati only

apraheya → bhāvanā-heya
    puruṣakāra
    adhipati

apraheya → apraheya
    niḥṣyanda
    visaṃyoga
    puruṣakāra
    adhipati
    [vipāka excluded]
```

The final cell is therefore not “all five.” The missing fruit is `vipāka`.

### 2. Why repeat yathākramam?

Vasubandhu explicitly comments on the repeated `yathākramam`:

```text
punar yathākramagrahaṇam ādyantavan madhye 'pi jñāpanārtham
```

The repetition prevents ambiguity in the compressed enumeration. The middle member is governed by the same ordered correspondence as the first and last.

The remark:

```text
eṣa hi peyāladharmaḥ
```

identifies the style as an abbreviated or elliptical recitational construction. This is a valuable hermeneutic warning: the Kārikā is not meant to be read as self-expanding prose.

### 3. A new classification begins

The text then shifts away from the fruit matrix. The śāstras distinguish three kinds of karma:

```text
ayogavihita

yogavihita

neither
```

The question is not about fruit-counts but about **the mode in which an action is constituted or performed**.

### 4. First reported definition: affliction

**Voice: reported school position**

```text
kliṣṭaṃ karmāyogavihitam
```

Afflicted karma is improperly constituted because it arises from:

```text
ayoniśomanaskāra
    improper / non-methodical attention
```

This is a genesis definition:

```text
improper attention
    → afflicted karma
    → ayogavihita
```

### 5. Second reported definition: procedural deviation

**Voice: another reported position**

The category also includes:

```text
vidhibhraṣṭa
    action fallen away from the proper procedure
```

Examples are deliberately ordinary:

```text
how one should go
how one should stand
how one should eat
how one should move about
```

If the action is performed otherwise than the appropriate mode requires, its very execution is `ayukta-vidhāna`, unsuitable constitution or procedure.

Thus:

```text
wrong genesis
    is one ground

wrong mode of execution
    is another ground
```

The two should not be collapsed.

### 6. Properly constituted action

**Voice: reported position**

The counterpart is:

```text
kuśalaṃ karma yogavihitam
```

wholesome karma is properly constituted, and another formulation adds:

```text
avidhibhraṣṭa
    not deviating from proper procedure
```

Thus `yogavihita` can be characterized ethically and procedurally.

### 7. Neither category

What belongs to neither side is:

```text
naiva-yogavihitaṃ nāyogavihitam
```

This prevents a false exhaustive binary:

```text
proper
vs improper
```

The system explicitly preserves a third class.

---

## Voices

- **Vasubandhu:** frames the question, explains the apraheya fruit row, and reports the alternative definitions.
- **Reported position 1:** afflicted karma is `ayogavihita` because it arises from `ayoniśomanaskāra`.
- **Reported position 2:** procedurally deviant action is also `ayogavihita`.
- **Reported position 3:** wholesome and procedurally non-deviant action is `yogavihita`.
- **Final doctrinal adjudication in this passage:** not explicitly forced beyond the reported alternatives.

---

## New Technical Terms

- **ayogavihita** — improperly constituted, improperly applied, or improperly performed karma.  
  **Status:** new local classification.  
  **Function:** classifies action by genesis and/or conformity to appropriate procedure.

- **yogavihita** — properly constituted or properly applied karma.  
  **Status:** new local classification.  
  **Function:** counterpart of `ayogavihita`.

- **naiva-yogavihita-na-ayogavihita** — neither properly nor improperly constituted.  
  **Status:** new local third class.  
  **Function:** blocks reduction of the classification to a binary opposition.

- **ayoniśomanaskāra** — improper, non-methodical, or unwise attention.  
  **Status:** familiar Abhidharma causal term, newly central here.  
  **Function:** causal genesis of afflicted karma in one definition of `ayogavihita`.

- **vidhibhraṣṭa** — fallen away from prescribed or appropriate procedure.  
  **Status:** Bhāṣya-explicit refinement.  
  **Function:** extends improper action from afflicted genesis to defective execution.

- **peyāla-dharma** — abbreviated/elliptical recitational construction.  
  **Status:** Bhāṣya-only hermeneutic remark in this unit.  
  **Function:** explains why the Kārikā requires ordered supplementation rather than literal atomized reading.

## Doctrinal Determination

### The completed abandonment matrix

The three abandonment statuses do not form a symmetric result relation.

```text
C(darśana, bhāvanā) = 4
C(bhāvanā, darśana) = 2

C(darśana, apraheya) = 1
C(apraheya, darśana) = 1

C(bhāvanā, apraheya) = 3
C(apraheya, bhāvanā) = 2
```

Even where cardinalities coincide, membership need not.

The decisive point remains:

```text
fruit-relation
    is determined by the ordered pair
    source-status × result-status
```

### Improper action is not merely “bad action”

The Bhāṣya prevents a purely moralized translation of `ayogavihita`.

One account does connect it with afflicted karma. But another explicitly extends it to **procedural mis-performance**.

Therefore:

```text
ayogavihita
    may concern ethical affliction
    and/or procedural non-conformity
```

This is wider than simply “unwholesome.”

### Procedure is ethically relevant without becoming identical to ethics

A bodily routine such as standing, walking, eating, or moving can be malformed relative to an appropriate mode without introducing a new substance or new karmic medium.

The Bhāṣya is therefore distinguishing:

```text
what action is

from

how action is constituted and executed
```

---

## Translation Consequences

The first-pass rendering “improperly performed” for `ayogavihita` is useful but should remain broader than mere procedural error. The Bhāṣya gives two explanatory routes:

```text
improper genesis from ayoniśomanaskāra

and

improper execution through vidhibhraṃśa
```

A suitable project translation is therefore:

```text
ayogavihita
    improperly constituted action
```

with contextual glosses such as “improperly performed” where procedure is explicitly at issue.

Likewise:

```text
yogavihita
    properly constituted action
```

is preferable to a translation that reduces it immediately to “wholesome action,” because the Bhāṣya also gives a procedural definition.

## Light Organon Contact

The fruit matrix closes a long demonstration that causal relations are **typed and directed**. VAK 4.94 then shifts from output-relations to the constitution of the act itself.

A minimal structural distinction is:

```text
Action {
    ethicalQuality
    genesis
    prescribedMode
    actualMode
    constitutionStatus
}
```

Then:

```text
ImproperAttention(genesis)
    may determine
Ayogavihita(action)
```

and independently:

```text
ActualMode(action) ≠ AppropriateMode(action)
    may determine
Ayogavihita(action)
```

The useful logical point is that **defect can enter either through genesis or through execution**.

No larger Organon identification is required here.

## Summary

VAK 4.94 performs two jobs.

First, it completes the abandonment-status fruit matrix:

```text
apraheya karma
    → darśana-heya: 1 = adhipati
    → bhāvanā-heya: 2 = puruṣakāra + adhipati
    → apraheya: 4 = all except vipāka
```

Second, it opens a new threefold classification of action:

```text
ayogavihita
    improperly constituted

yogavihita
    properly constituted

neither
```

The Bhāṣya gives two grounds for improper constitution:

```text
improper attention → afflicted genesis

or

falling away from proper procedure → defective execution
```

Thus the passage moves from **the differentiated causal relations of karma** to **the internal correctness of karmic performance itself**.
