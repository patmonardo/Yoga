# VAK_2.71_bhasya — From Twelve Cittas to Twenty

## Kārikā

```text
tasmāc catvāri cittāni dvādaśaitāni viṃśatiḥ /
prāyogikopapattyāptaṃ śubhaṃ bhittvā triṣu dvidhā // VAkK_2.71 //
```

## Bhāṣya — Continuous Translation

Thus the twelve cittas are completed. They are again made into twenty. How? By dividing wholesome citta in each of the three realms into two: that produced through application or practice (`prāyogika`) and that obtained by rebirth (`upapattilābhika`).

## Voices

- **Voice: Vasubandhu / expository Abhidharma voice** — refines the previously established twelvefold citta classification.

## New Technical Terms

- **prāyogika** — produced or acquired through application, effort, or practice.
  - **status** — new as a decisive classification feature in this passage.
  - **function** — acquisition-mode feature distinguishing cultivated wholesome citta from naturally rebirth-acquired wholesome citta.
- **upapattilābhika / upapattyāpta** — obtained through rebirth in a realm.
  - **status** — new as a decisive classification feature here.
  - **function** — acquisition-mode feature opposed to `prāyogika`.
- **bhid / bhittvā** — divide, split, refine a class.
  - **status** — ordinary lexical item used technically in the classification operation.
  - **function** — feature refinement of a previously valid class without abolishing the coarser class.

## Translation Consequences

The twelvefold citta matrix is not replaced by the twentyfold matrix. Rather, the former is refined by adding a new discriminating feature: mode of acquisition. In each of the three realms, wholesome citta is split into practice-acquired and rebirth-acquired forms.

This is important for the structure of the analysis: the Kośa permits hierarchical classification. A valid class at one level can be subdivided at a finer level when a new causal or functional distinction becomes relevant.

## Doctrinal / Logical Determination

```text
Base classification:
    12 citta-types

Refinement feature:
    acquisitionMode
        = prāyogika
        | upapattilābhika

Applied to:
    wholesome citta in kāma
    wholesome citta in rūpa
    wholesome citta in ārūpya

Result:
    20 citta-types
```

The key logical operation is feature refinement rather than replacement.

```text
Citta[realm=X, wholesome]
    -> Citta[realm=X, wholesome, acquisition=practice]
    -> Citta[realm=X, wholesome, acquisition=rebirth]
```

## Organon Interpretation

VAK 2.71 gives a direct model for how the Organon Dataset should grow. A coarse feature grammar can remain valid while a richer Workbook introduces a new feature dimension and expands the state-space.

```text
Dataset v1:
    Citta[realm, status]

Dataset v2:
    Citta[realm, status, acquisitionMode]
```

The second does not invalidate the first. It refines it.

This is exactly the bootstrapping pattern wanted for Organon Light: classifications are promoted progressively as distinctions become textually and logically warranted, while the browsable Workbook preserves the reason for each refinement.

## Summary

VAK 2.71 expands the twelvefold citta system into twenty by distinguishing cultivated wholesome citta from wholesome citta obtained by rebirth. The verse therefore introduces a formally important operation: hierarchical feature refinement of an already valid classification.
