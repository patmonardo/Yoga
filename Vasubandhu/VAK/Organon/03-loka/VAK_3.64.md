# VAK_3.64

## 1. Sanskrit (Devanāgarī)

> करोटपाणयस्तासु मालाधाराः सदामदाः ।
>
> महाराजिकदेवाश्च पर्वतेष्वपि सप्तसु ॥ ३.६४ ॥

## 2. Sanskrit (IAST)

> karoṭapāṇayas tāsu mālādhārāḥ sadāmadāḥ /
>
> mahārājikadevāś ca parvateṣv api saptasu // 3.64 //

## 3. Padaccheda and Lexical Analysis

```text
karoṭa-pāṇayaḥ            → karoṭapāṇayas
tāsu                       → tāsu
mālā-dhārāḥ                → mālādhārāḥ
sadā-madāḥ                 → sadāmadāḥ
mahārājika-devāḥ           → mahārājikadevāś
ca                         → ca
parvateṣu                  → parvateṣv
api                        → api
saptasu                    → saptasu
```

| Form | Morphology | Lexical force here |
|---|---|---|
| karoṭapāṇayaḥ | nominative masculine plural compound | Karoṭapāṇis, a named class of terrace inhabitants |
| tāsu | locative feminine plural pronoun | on those, referring to the four terraces of 3.63 |
| mālādhārāḥ | nominative masculine plural compound | Mālādhāras, garland-bearers |
| sadāmadāḥ | nominative masculine plural compound | Sadāmadas, the perpetually exhilarated or intoxicated |
| mahārājikadevāḥ | nominative masculine plural compound | Mahārājika devas, devas belonging to the Great Kings |
| ca | conjunction | and |
| parvateṣu | locative masculine plural | on the mountains |
| api | indeclinable | also, extending the range of habitation |
| saptasu | locative masculine plural numeral | on the seven |

`Karoṭapāṇi`, `Mālādhāra`, and `Sadāmada` are retained as class-names. Their
literal components assist recognition but do not replace their classificatory
function in this passage.

## 4. Grammar and Construe

The first line places three named populations on the terraces previously
defined:

```text
tāsu [pariṣaṇḍāsu]
    karoṭapāṇayaḥ,
    mālādhārāḥ,
    sadāmadāḥ [prativasanti]
```

The Kārikā compresses the distribution. The Bhāṣya assigns the Karoṭapāṇis to
the first terrace, the Mālādhāras to the second, and the Sadāmadas to the
third. It then supplies the fourth member: the Four Great Kings themselves and
their attendants reside on the fourth terrace.

The second line extends the Mahārājika population beyond the terraces:

```text
mahārājika-devāḥ ca
    saptasu parvateṣu api [prativasanti]
```

> And Mahārājika devas also [reside] on the seven mountains.

The Bhāṣya specifies their presence there through villages and towns on the
seven mountains beginning with Yugandhara.

## 5. Translation

### Close syntactic construe

> On those [terraces are] the Karoṭapāṇis, the Mālādhāras, and the Sadāmadas;
> and Mahārājika devas are also on the seven mountains.

### Bhāṣya-informed study translation

> Karoṭapāṇi yakṣas inhabit the first terrace, Mālādhāras the second, and
> Sadāmadas—also called Sadāmattas—the third. The Four Great Kings themselves
> and their attendants inhabit the fourth. All these belong to the host of the
> Four Great Kings. That same class also has villages and towns on the seven
> mountains beginning with Yugandhara.

The terrace-by-terrace assignment, identification of the Karoṭapāṇis as
yakṣas, fourth-terrace population, common Cāturmahārājakāyika classification,
and settlement forms are Bhāṣya determinations.

## 6. Philosophical Translation

> The measured terraces of 3.63 now become inhabited domains. Each level
> receives a differentiated population, yet those local differences are
> gathered under one encompassing class: the host of the Four Great Kings.
> This class is not confined to a single vertical structure; its habitation
> extends through settlements on the seven surrounding mountains. The World
> System therefore articulates agency by coordinating position, population,
> collective membership, and territorial extension.

## 8. Logical Determination

### Ordered terrace assignment

Let `T₁–T₄` be the terraces specified in 3.63:

| Terrace | Resident population | Additional determination |
|---:|---|---|
| `T₁` | Karoṭapāṇis | yakṣas |
| `T₂` | Mālādhāras | terrace-devas |
| `T₃` | Sadāmadas / Sadāmattas | terrace-devas |
| `T₄` | Four Great Kings and attendants | governing center |

This mapping is a Bhāṣya resolution of the Kārikā's compressed list.

### Local differentiation and common classification

```text
Karoṭapāṇis        ∈ Cāturmahārājakāyikas
Mālādhāras         ∈ Cāturmahārājakāyikas
Sadāmadas          ∈ Cāturmahārājakāyikas
Four Great Kings
  and attendants   ∈ Cāturmahārājakāyikas
```

Distinct residence classes can therefore remain members of one encompassing
deva host. Difference of level does not entail difference of the highest
classification relevant here.

### Three independent relations

```text
residence:
    population → terrace or mountain settlement

classification:
    population → Cāturmahārājakāyika host

governance:
    Four Great Kings + attendants → fourth terrace
```

These relations must not be collapsed. A location is not a class, and common
class-membership does not erase the ordered distribution of residences.

### Territorial extension

```text
Meru terraces
    + settlements on seven mountains
        → distributed Mahārājika domain
```

The particle `api`, “also,” is logically important: it expands the extension
of the population without replacing its terrace habitations.

## 9. Interpretive Note

VAK 3.63 and 3.64 form a precise two-stage construction:

```text
3.63  geometric schema
          → four ordered, measured locations

3.64  population schema
          → differentiated occupants
          → common class
          → extended settlements
```

This is why the ostensibly picturesque catalogue remains methodically useful.
The World System does not introduce agents into an unarticulated expanse. It
first establishes addressable domains, then binds populations to those
addresses, then identifies a higher-order class that ranges across several
locations.

The Bhāṣya also prevents a simple one-place/one-class model. The
Cāturmahārājakāyikas occupy differentiated terraces and have villages and
towns across seven mountains. One collective can therefore be spatially
distributed while retaining its classificatory unity.

```ts
interface PopulationBinding {
  population: string;
  residence: string;
  collective: "Caturmaharajikayika";
  role?: "ruler" | "attendant" | "resident";
}

interface DistributedDomain {
  governingCenter: "FourthMeruTerrace";
  terraceBindings: readonly PopulationBinding[];
  mountainSettlements: readonly ("Village" | "Town")[];
}
```

This is explanatory project notation, not Vasubandhu's vocabulary. It makes
explicit the semantic discrimination required by the passage: `resides-at`,
`belongs-to-class`, and `governs-from` are different predicates even when
they concern the same inhabitants.

The Agential abstraction is accordingly not “devas exist,” but:

```text
Agent class
    + spatial address
    + collective membership
    + differentiated role
        → socially articulated World domain
```

The produced Physical World is already becoming the support of ordered
practical relations. That prepares the movement toward Karma without
mistaking the present cosmographical classification for Karma doctrine itself.
