# VAK_3.16

## 1. Sanskrit (Devanāgarī)

> सम्प्रजानन् विशत्येकः तिष्ठत्यप्यपरः अपरः ।
>
> निष्क्रामत्यपि सर्वाणि मूढोऽन्यः नित्यमण्डजः ॥ ३.१६ ॥

## 2. Sanskrit (IAST)

> saṃprajānan viśaty ekaḥ tiṣṭhaty apy aparaḥ aparaḥ /
>
> niṣkrāmaty api sarvāṇi mūḍho 'nyaḥ nityam aṇḍajaḥ // 3.16 //

## 3. Padaccheda and Lexical Analysis

```text
saṃprajānan                 → saṃprajānan
viśati + ekaḥ               → viśaty ekaḥ
tiṣṭhati + api + aparaḥ     → tiṣṭhaty apy aparaḥ
aparaḥ                      → aparaḥ
niṣkrāmati + api            → niṣkrāmaty api
sarvāṇi                     → sarvāṇi
mūḍhaḥ + anyaḥ              → mūḍho 'nyaḥ
nityam + aṇḍajaḥ            → nityam aṇḍajaḥ
```

| Form | Morphology | Lexical force here |
|---|---|---|
| saṃprajānan | nominative masculine singular present participle | knowing clearly; clearly aware |
| viśati | third-person singular present of √viś | enters |
| ekaḥ | nominative masculine singular | one [type] |
| tiṣṭhati | third-person singular present of √sthā | remains; stays |
| api | additive particle | also; carries entry and clear awareness forward cumulatively |
| aparaḥ | nominative masculine singular | another; a further type |
| niṣkrāmati | third-person singular present of nis-√kram | exits; comes forth |
| sarvāṇi | accusative neuter plural | all [three actions] |

| anyaḥ | nominative masculine singular | another [type] |
| nityam | adverb | always; invariably |
| aṇḍajaḥ | nominative masculine singular | one who is or will be egg-born |

The Bhāṣya explicitly carries `saṃprajānan` and the earlier actions forward
through each `api`. The three clear profiles are therefore cumulative, not
three isolated moments.

## 4. Grammar and Construe

The cumulative syntax yields four profiles:

```text
ekaḥ
    saṃprajānan viśati

aparaḥ
    saṃprajānan viśati
    saṃprajānan tiṣṭhati api

aparaḥ
    saṃprajānan viśati
    saṃprajānan tiṣṭhati
    saṃprajānan niṣkrāmati api

anyaḥ
    sarvāṇi mūḍhaḥ [karoti]
```

The final compressed rule is:

```text
aṇḍajaḥ
    nityam mūḍhaḥ
    sarvāṇi [karoti]
```

The Bhāṣya says these four womb-descents are stated in reverse order for the
construction of the verse. Surface sequence therefore does not itself encode
their doctrinal ranking.

## 5. Translation

### Close syntactic construe

> One enters with clear awareness; another also remains [with clear
> awareness]; a further one also exits [with clear awareness]. Another is
> deluded in all [three stages]; one who will be egg-born is always [deluded].

### Bhāṣya-informed study translation

> Four womb-descents are distinguished. One is clearly aware upon entry;
> another upon entry and residence; another throughout entry, residence, and
> emergence. A fourth undergoes all three stages under delusion. The egg-born
> case is invariably of the deluded type, with “egg-born” applied prospectively
> to one who will emerge from an egg.

The fourfold `garbhāvakrānti` framework, cumulative scope, reversed metrical
order, and prospective designation of the egg-born are Bhāṣya determinations.

## 6. Philosophical Translation

> Embodiment has a cognition-profile as well as a biological mode. Clear
> awareness may persist through progressively more of entry, gestation, and
> emergence. Delusion is not mere blankness: the actual transition is
> recognized and taken as another environment. Clarity consists here in the
> non-arising of that inverted recognition and determination.

## 8. Logical Determination

### The four profiles are cumulative

Let the ordered transition phases be:

```text
P = [Entry, Residence, Exit]
```

Then:

```text
Profile 1
    Clear = [Entry]

Profile 2
    Clear = [Entry, Residence]

Profile 3
    Clear = [Entry, Residence, Exit]

Profile 4
    Deluded = [Entry, Residence, Exit]
```

The `api` particles perform the cumulative work. They prevent Profile 2 from
meaning “clear only while remaining” and Profile 3 from meaning “clear only
while exiting.”

### Delusion is structured substitution

For a being of lesser status, the Bhāṣya gives such appearances as storm,
cold, darkness, commotion, thicket, forest, hut, or tree-root. For one of
greater status, the appearances may be park, garden, palace, pavilion, or
couch.

The form is constant:

```text
actual process
    womb-entry / residence / emergence

viparīta-saṃjñā
    presents another environment

viparīta-adhimokṣa
    determines “this is where I enter / remain / emerge”
```

Thus:

```text
mūḍhatā
    = inverted recognition
      + inverted taking-to-be
```

### Clear awareness is locally defined

The Bhāṣya defines the clear case economically:

```text
saṃprajānan
    → viparīta-saṃjñā does not arise
    → viparīta-adhimokṣa does not arise
```

It does not add a separate higher cognitive faculty in this unit. The study
must preserve that restraint.

### Prospective naming resolves the egg-born objection

```text
future state = egg-born
    → prospective designation “egg-born”
       can apply during womb-descent
```

The Bhāṣya resolves the apparent biological contradiction through the temporal
scope of designation, not through a new birth-mechanism.

## 9. Interpretive Note

VAK 3.16 adds epistemic telemetry to embodiment. The World System records not
only where and how a continuity is born, but how much clarity persists through
the transition's three phases.

```text
birth-mode
destination
entry phase
residence phase
exit phase
clarity profile
presentation profile
determination profile
```

This is Transcendental Technē as project architecture. The transition can be
perfectly operative while its lived presentation is systematically false.
The Agent does not simply lack the correct report; another experiential world
is rendered and accepted in its place.

For the NLP Pipeline of Meaning, the distinction is exact:

```text
Field-process
    actual womb-transition

saṃjñā layer
    environment is presented

adhimokṣa layer
    presentation is stabilized as what is occurring

Agent report
    “I enter / remain in / leave this environment”
```

`Jagan mithyā` again gains a concrete local determination. Forest, hut,
garden, and palace are neither accurate disclosures of the operative process
nor causally idle fantasies. They are the appearance-world through which the
Agent undergoes a real transition.

But clear awareness is possible inside the World System. The first three
profiles show progressively sustained freedom from inversion through entry,
residence, and emergence. This is not yet `prajñā`; it is the increasingly
stable cognition-platform upon which higher knowing may later become
possible.

The text has now moved from destination-selection to perception during
embodiment itself. VAK 3.17 will identify the exceptional beings assigned to
the three clear profiles; that identification is deliberately not anticipated
here.
