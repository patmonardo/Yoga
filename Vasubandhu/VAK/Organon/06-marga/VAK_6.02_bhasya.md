## 3. Continuous Conventional Translation

> “Seeing the truths” was said. Which, and how many? Four, already named in the
> contaminated/uncontaminated exposition. Is the old listing-order the order here?
> No: suffering, origin, cessation, Path. Order follows direct realization.
>
> What is realized first is taught first. If this were cause-order, origin would
> come first. Some teachings follow arising-order; some follow exposition-order.
> The truths follow realization-order.
>
> Why this realization? At examination one first inspects that in which one
> stands, by which one is struck, from which one wants out — suffering. Then its
> cause, its cessation, the path to that cessation. As examined, so realized —
> prior penetration.
>
> *Abhisamaya*: full awakening-knowing. Uncontaminated: right knowing facing
> nirvāṇa; “right” = according to reality. Appropriated aggregates as result =
> suffering; as cause = origin. Difference of those two: name, not separate
> substance. Cessation and path differ also as realities.
>
> Called noble truths because noble ones see them as they are. Not false for
> others — they are non-inverted for all. Others do not see them so.

## 4. Movement of the Commentary

```text
which truths → this order ≠ cause-order

noble names the seeing, not a private truth
```

## 5. Realization-Order ≠ Causal Order

Duḥkha/samudaya ≠ two substances. Nirodha ≠ mārga. Abhisamaya ≠ a flash without
trajectory. “Noble” ≠ true only for nobles.

## 6. Two Orders

| | |
|---|---|
| cause → result | samudaya → duḥkha |
| realization | duḥkha → samudaya → nirodha → mārga |

## 7. The Bhāṣya's Decisions for the Kārikā

- `yathābhisamayam` governs `krama`;
- `tathā` keeps natures as already taught;
- ārya-satya = adequate seeing of a public truth.
