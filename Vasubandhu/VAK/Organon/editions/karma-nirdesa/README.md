# Karmanirdeśa Special Edition

This directory contains the provisional PDF reading edition generated from
the first 66 current studies in `Organon/04-karma`, VAK 4.01–4.66.

The study files remain the canonical editable sources. The PDF is a derived
reading artifact. Every kārikā begins on a new page, while long individual
studies may continue across as many pages as required.

This is a special work-in-progress edition of the first half of the
Karmanirdeśa. It does not represent the completed chapter. The second half
will be incorporated as its verse studies are prepared and reviewed.

Build requirements:

- Pandoc
- XeLaTeX
- FreeSerif, Lato, and FreeMono fonts

Run `./build.sh` from this directory to rebuild the PDF.
