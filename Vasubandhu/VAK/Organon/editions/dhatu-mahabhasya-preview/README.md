# Dhātu Mahābhāṣya Preview

This working edition compiles the 48 initial Bhāṣya-analysis files from
`Vasubandhu/VAK/01-dhatu/` in canonical order. It is a size and readability
preview for the future compulsory-method Mahābhāṣya upgrade; the source files
are included without editorial rewriting.

Build with:

```bash
./build.sh
```

Output:

```text
Organon-Kosa-Dhatu-Mahabhasya-Preview.pdf
```
