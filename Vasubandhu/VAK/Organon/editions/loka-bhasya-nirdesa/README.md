# Lokanirdeśa Bhāṣya

Sequential Chapter 3 reading edition: 38 Bhāṣya studies, VAK 3.01–3.38.
The studies remain provisional where textual questions or review
qualifications are recorded.

Canonical editable sources are `Organon/03-loka/VAK_3.01_bhasya.md`
through `VAK_3.38_bhasya.md`. The PDF preserves the full Sanskrit,
continuous conventional translations, and focused studies in sequence.
Commentary-unit boundaries sometimes cross kārikā boundaries as explained
in the individual studies. Kārikā-only studies are not build inputs.

Run `./build.sh` from this directory. Requires Pandoc, XeLaTeX,
and the FreeSerif, Lato, and FreeMono fonts.

Output: `Organon-Kosa-Loka-Bhasya-Nirdesa.pdf`
