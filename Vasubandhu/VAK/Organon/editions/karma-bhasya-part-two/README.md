# Karmanirdeśa Bhāṣya, Part Two

Provisional reading edition of fifty-four consecutive official Bhāṣya
studies, VAK 4.13–4.66. This continues Part One (VAK 4.01–4.12).
It is a reading range, not a doctrinal section of the Kośa or a
complete chapter edition.

The Markdown studies in `Organon/04-karma` are the canonical editable
sources. This derived PDF presents continuous Sanskrit, conventional
translation, and focused study. Readings remain provisional, including
the marked textual problems in individual studies.

Run `./build.sh` from this directory. Requires Pandoc, XeLaTeX, and
the FreeSerif, Lato, and FreeMono fonts.

Output: `Organon-Kosa-Karma-Bhasya-Nirdesa-Part-Two.pdf`
