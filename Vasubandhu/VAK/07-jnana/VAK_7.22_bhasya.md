# VAK_7.22 — Bhāṣya

## Kārikā

> ṣoḍaśe ṣaṭ sarāgasya vītarāgasya sapta tu /
> sarāgabhāvanāmārge tadūrdhvaṃ saptabhāvanā // VAK_7.22 //

**Best current translation:**  
At the sixteenth moment, six knowledges are cultivated by one possessing desire, but seven by one detached from desire. Above that, in the Path of Cultivation while desire remains, there is cultivation of seven knowledges.

**Kārikā analysis:** [`VAK_7.22.md`](./VAK_7.22.md)

## Natural Argument

### 1. The sixteenth moment: six cultivated knowledges

**Voice: Vasubandhu**

The Bhāṣya carries forward `bhāvyante`, “are cultivated.”

For the practitioner who is not yet detached from desire (`avītarāga`), at the sixteenth moment of the noble sequence — `mārgānvayajñāna` — two knowledges are presently occurring:

```text
mārgajñāna
    knowledge of the Path

mārgānvayajñāna
    inferential knowledge of the Path
```

But the cultivation count concerns six already-established knowledge species:

```text
dharmajñāna
anvayajñāna
duḥkhajñāna
samudayajñāna
nirodhajñāna
mārgajñāna
```

Thus the Bhāṣya distinguishes sharply between:

```text
what is present now
    pratyutpanna

and

what is cultivated
    bhāvyamāna
```

The two lists overlap, but they are not the same question.

### 2. The already detached practitioner: seven

**Voice: Vasubandhu**

For the practitioner already detached from desire, `paracittajñāna` — knowledge of another mind — is cultivated as the seventh.

So at exactly the same sixteenth path-moment:

```text
not previously detached
    six cultivated knowledges

previously detached
    seven cultivated knowledges
```

The difference is determined by prior attainment, not by a different present noble cognition.

### 3. After the sixteenth moment: seven throughout the desire-associated Path of Cultivation

**Voice: Vasubandhu**

After the sixteenth moment, so long as the practitioner has not yet become detached from desire, seven knowledges are cultivated in all four kinds of Path of Cultivation:

```text
prayoga-mārga
    preparatory path

ānantarya-mārga
    uninterrupted path

vimukti-mārga
    liberation path

viśeṣa-mārga
    special / excellent path
```

The seven are:

```text
dharmajñāna
anvayajñāna
duḥkhajñāna
samudayajñāna
nirodhajñāna
mārgajñāna
saṃvṛtijñāna
```

Here `paracittajñāna` is not the seventh. The seventh is conventional knowledge.

### 4. Present cognition varies while the cultivation field remains sevenfold

The Bhāṣya adds a useful distinction not explicit in the verse.

If the Path of Cultivation is worldly (`laukika`):

```text
present cognition
    = saṃvṛtijñāna
```

If it is transworldly (`lokottara`):

```text
present cognition
    = one of the four dharmajñānas
```

Nevertheless, in both cases the same sevenfold cultivation field is established.

This prevents a common confusion:

```text
present cognition species
    ≠
complete set of knowledges being cultivated
```

## Argument Reconstruction

The movement from VAK 7.19 to 7.22 can now be stated more exactly:

```text
7.19
possession of knowledge
    samanvāgama

7.20–7.21
cultivation in Seeing
    present realization establishes future determinate capacity

7.22
cultivation in the Path of Cultivation
    depends jointly on
        present path-stage
        prior detachment
        worldly or transworldly mode
```

The Path is therefore being represented as a differentiated cognitive economy, not as a simple sequence of isolated insights.

## New Technical Terms

- **purāgata** — previously arisen / previously attained
  - **status:** Bhāṣya explanatory vocabulary in this passage
  - **function:** marks the six knowledge species already established before the sixteenth moment and now cultivated

- **pratyutpanna-jñāna** — presently occurring knowledge
  - **status:** Bhāṣya classificatory vocabulary
  - **function:** distinguishes the cognition actually occurring in the present path-moment from the wider set of knowledges cultivated

- **prayoga-mārga** — preparatory path
  - **status:** path-taxonomic term developed in the Bhāṣya
  - **function:** one of four modes in which seven knowledges are cultivated after the sixteenth moment while desire remains

- **ānantarya-mārga** — uninterrupted path
  - **status:** established path term
  - **function:** directly removes the targeted defilement; included in the sevenfold cultivation rule

- **vimukti-mārga** — liberation path
  - **status:** established path term
  - **function:** immediately follows the uninterrupted path and confirms liberation from the abandoned factor

- **viśeṣa-mārga** — special / superior path
  - **status:** Bhāṣya path-taxonomic term
  - **function:** fourth mode of post-sixteenth cultivation included under the same sevenfold rule

- **laukika-bhāvanāmārga** — worldly Path of Cultivation
  - **status:** explicit Bhāṣya distinction
  - **function:** determines that the presently occurring cognition is conventional knowledge

- **lokottara-bhāvanāmārga** — transworldly Path of Cultivation
  - **status:** explicit Bhāṣya distinction
  - **function:** determines that the presently occurring cognition is one of the four dharma-knowledges

## Doctrinal Determination

### The sixteenth moment is a hinge

The sixteenth moment remains continuous with the sixteen moments of direct comprehension, but it is also the point from which the Bhāṣya begins reckoning the continuing Path of Cultivation.

At this hinge, the practitioner does not simply “have six knowledges.” Rather:

```text
presently occurring
    two knowledge determinations

cultivated as future capacity
    six knowledge species
```

This is exactly the distinction established in 7.20–7.21 between actual occurrence and cultivation.

### Prior detachment changes what can be cultivated

The addition of `paracittajñāna` for the detached practitioner shows that cultivation is historically conditioned.

```text
same noble moment
    + different prior attainment
        ↓
    different cultivation range
```

A path-moment therefore cannot be interpreted without the practitioner's attained history.

### The later seven are not the same seven as at the sixteenth moment

This is an important correction to any loose reading of the Kārikā.

At the sixteenth moment for the detached practitioner, the seventh is:

```text
paracittajñāna
```

After the sixteenth moment, while desire remains, the sevenfold set is:

```text
six pure truth-related knowledges
    +
saṃvṛtijñāna
```

Thus identical numerical counts can conceal different internal compositions.

### Cultivation exceeds present occurrence

The Bhāṣya's worldly/transworldly distinction makes the structural point explicit.

In a worldly cultivation-path moment, conventional knowledge is presently occurring. In a transworldly cultivation-path moment, one of the four dharma-knowledges is presently occurring. But in either case seven species are cultivated.

Therefore:

```text
bhāvanā
    is not identical with
    present cognitive occurrence
```

Cultivation names the transformation and stabilization of the continuum's cognitive powers across a wider field than the presently manifest cognition.

## Translation Consequences

The existing Kārikā translation is sound.

Two Bhāṣya clarifications should control its interpretation:

1. `ṣaṭ` and `sapta` count **cultivated knowledge species**, not the number of simultaneous cognitions.
2. The second `sapta` has a different composition from the seven cultivated by the previously detached practitioner at the sixteenth moment.

The translation “while desire remains” for `sarāga` is preferable here to a psychological “with passion,” because the Bhāṣya glosses the status through whether detachment has been attained.

## Logical Determination

VAK 7.22 gives a precise distinction among three dimensions:

```text
path-position
    where the practitioner stands

attainment-history
    what has already been overcome or acquired

cultivation-range
    which determinate cognitive powers are being developed
```

The relation is many-to-many rather than one-to-one.

The same present cognition can participate in a larger field of cultivation, and the same numerical cultivation count can contain different knowledge species depending upon the practitioner's history.

This prevents reduction of the Path to a linear sequence of mental events.

More exactly:

```text
present cognition
    is one actual determination

cultivation
    is the mediated expansion / stabilization
    of the continuum's determinate powers
```

## Organon Contact Point

Light contact only:

The verse strengthens the emerging model of **knowledge as historically acquired capacity**.

```text
what a system can now cultivate
    depends on
what it has already become
```

The present state cannot be understood atomistically. It is internally mediated by prior attainment.

The worldly/transworldly distinction adds another useful result:

```text
one determination is actual now

while

a wider organized field of determinations
is being reproduced and strengthened
```

This is closer to a science maintaining and developing an articulated competence than to a mere series of representations.

No stronger Organon identification is required here; VAK 7.23–7.26 will enlarge the cultivation matrix and should control any further synthesis.
