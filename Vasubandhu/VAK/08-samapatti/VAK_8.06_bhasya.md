# VAK_8.06 — Bhāṣya

## Kārikā

> āsvādanāsaṃprayuktaṃ satṛṣṇaṃ laukikaṃ śubham /
> śuddhakaṃ tattadāsvādyaṃ lokottaramanāsravam // VAK_8.06 //

**Best current translation:**  
That which is associated with savoring is accompanied by craving. The worldly wholesome attainment is pure; each corresponding pure attainment is what is savored. The supramundane attainment is uncontaminated.

**Kārikā analysis:** [`VAK_8.06.md`](./VAK_8.06.md)

## Source Caution

The working e-text is based principally on Pradhan with corrections from Shastri and is not a critical edition. The prose is unusually explicit here and should control the translation of the compressed kārikā. In particular, `āsvādanā` is not merely pleasant experience: Vasubandhu identifies it directly with `tṛṣṇā`. Likewise, `śuddhaka` is not supramundane purity; it is worldly wholesome samāpatti conjoined with pure dharmas such as non-greed.

## Natural Argument

**Voice: Vasubandhu**

Vasubandhu first defines the savoring-associated mode by its kleśic determinant. `Āsvādanā` is craving (`tṛṣṇā`). Therefore a samāpatti associated with savoring is one in which the attainment is appropriated through thirst or relish.

He then defines the pure mode. A `śuddhaka` samāpatti is worldly (`laukika`) and wholesome (`kuśala`). It receives the name "pure" because it is conjoined with pure dharmas beginning with non-greed (`alobha`). Thus worldly purity and supramundane uncontamination are not identical.

Vasubandhu next asks what exactly is savored by a savoring-associated attainment. The answer is not an independent object nor some abstract pleasure. What is savored is the corresponding pure samāpatti that has just passed immediately before.

The temporal relation is explicit. One emerges from the pure attainment that is savored, while one enters the savoring-associated attainment by which that preceding state is relished.

Finally, Vasubandhu defines the uncontaminated mode. Whatever samāpatti is supramundane (`lokottara`) is uncontaminated (`anāsrava`).

The prose then transitions to the dhyāna-factor analysis of VAK 8.07.

## New Technical Terms

- **āsvādanā** — savoring or relishing, explicitly identified here with `tṛṣṇā`
  - **status:** present in the Kārikā; explicitly defined in the Bhāṣya
  - **function:** kleśic determinant distinguishing the savoring-associated mode

- **alobha** — non-greed
  - **status:** absent from the Kārikā; previously encountered as a wholesome root
  - **function:** example of the pure dharmas whose conjunction explains why worldly wholesome samāpatti is called `śuddhaka`

- **samanantarātīta** — immediately preceding and past
  - **status:** absent from the Kārikā
  - **function:** specifies the temporal relation between the pure attainment and the subsequent savoring that takes it as object

- **vyutthita** — emerged or arisen out of an attainment
  - **status:** Bhāṣya operational vocabulary
  - **function:** marks withdrawal from the pure attainment that becomes the object of savoring

## Doctrinal Determination

VAK 8.06 makes the three modes introduced in 8.05 doctrinally precise.

### 1. Savoring is craving

```text
āsvādanā
    = tṛṣṇā
```

This prevents a neutral translation such as mere "enjoyment." The attainment is being appropriated through craving.

The important point is that highly refined meditative states remain possible objects of attachment.

### 2. Pure does not mean supramundane

```text
śuddhaka
    laukika
    kuśala
    joined with alobha etc.
```

A meditative attainment can therefore be genuinely wholesome and pure while still belonging to the worldly order.

This confirms the distinction established in VAK 8.05:

```text
highest conditioned attainment
    ≠ liberative attainment
```

### 3. Savoring takes the corresponding pure attainment as object

The Bhāṣya gives a precise succession:

```text
pure attainment
    ↓ withdrawal
savoring-associated attainment
    ↓
relishes the immediately preceding pure state
```

The savoring mode is therefore not simply the pure attainment plus a simultaneous craving added to it. Vasubandhu describes an immediately successive relation in which the just-past pure samāpatti becomes the object of relish.

### 4. Uncontaminated is supramundane

```text
lokottara samāpatti
    = anāsrava samāpatti
```

The distinction is categorical rather than merely quantitative. `Anāsrava` does not mean a more intense degree of worldly purity.

## Translation Consequences

The first pāda should be translated strongly enough to preserve Vasubandhu's explicit equation:

> The savoring-associated mode is accompanied by craving, for savoring is craving.

`Śuddhaka` should remain "pure" only with the doctrinal qualification that it means worldly wholesome attainment joined with pure dharmas; it is not equivalent to `anāsrava`.

`tattadāsvādyam` should be read through the prose as the corresponding pure samāpatti that has immediately passed and is then relished by the savoring-associated state.

`lokottara` should be retained as "supramundane" rather than simply "higher," because the contrast is not cosmological elevation but freedom from the worldly order of outflows.

## Logical Determination

The same meditative level does not determine its own path-status.

```text
SamāpattiLevel
    ≠ ModalStatus
```

A single level may be related differently to craving and liberation:

```text
same level
    ├── craving appropriates it
    │       āsvādanāsaṃprayukta
    │
    ├── wholesome worldly cultivation
    │       śuddhaka
    │
    └── supramundane realization
            anāsrava
```

The Bhāṣya also introduces a significant temporal structure:

```text
state A
    pure attainment

state B
    savoring-associated attainment

B takes immediately past A as object
```

Thus classification depends not only on what state is present but on the relation between successive cognitive states.

A further rule follows:

> **Purity of state does not by itself determine freedom; the mode in which the state belongs to the path remains decisive.**

## Light Organon Contact

The restrained Organon point is that Chapter 8 is no longer classifying samāpatti only by internal composition. It is now classifying the same attainment by its practical relation to bondage and release.

```text
attainment structure
    tells us what configuration is present

modal status
    tells us how that configuration functions
    in relation to craving and liberation
```

The immediately preceding pure state becoming the object of savoring is especially instructive:

```text
excellent state
    does not immunize itself
    against subsequent appropriation
```

So phenomenological refinement and liberative status must remain separate dimensions.

No stronger Systems reconstruction is needed here. Vasubandhu's practical science is already precise: the same cultivated field can be relished, remain worldly-pure, or function supramundanely, and those differences are path-significant.
