# VAK_5.28 — Bhāṣya

## Kārikā

**VAK 5.28**

> prahīṇe duḥkhadṛggheye saṃyuktaḥ śeṣasarvagaiḥ |
> prāk prahīṇe prakāre ca śeṣais tadviṣayair malaiḥ || 5.28 ||

Best current translation:

> When what is to be abandoned by seeing suffering has been abandoned, one remains connected with it through the remaining universally ranging afflictions. And when a grade has previously been abandoned, one remains connected with it through the remaining defilements that take it as their object.

## Literal Prose Translation

Now this is examined: if an object (`vastu`) has been abandoned, is one disconnected (`visaṃyukta`) from that object? Or, wherever one is disconnected, has that object been abandoned by that person?

Wherever one is disconnected, that object has indeed been abandoned by that person. But something may have been abandoned while one is not yet disconnected from it. For example:

> When what is to be abandoned by seeing suffering has been abandoned, one remains connected with it through the remaining universally ranging afflictions. And with respect to a grade previously abandoned, one remains connected through the remaining stains that take it as their object.

When knowledge of suffering has arisen but knowledge of origination has not yet arisen, the class to be abandoned by seeing suffering has been abandoned. Even though that class has been abandoned, one remains connected with it through the universally ranging afflictions to be abandoned by seeing origination that take it as object.

Likewise, within the class to be abandoned by cultivation, among its nine grades, when some grade has previously been abandoned, even though that grade has been abandoned one is to be understood as still connected with it through the remaining afflictions that take it as their object.

If one were to state individually how many anuśayas lie latent with respect to each object, an excessively long account would result. Therefore a condensed exposition (`piṇḍavibhāṣā`) is made.

## Philosophical Translation

Abandonment and complete disconnection are not identical determinations. Complete disconnection entails that the relevant object has been abandoned, but abandonment alone does not entail complete disconnection.

A class of afflictions may have been eliminated from the practitioner's continuum while still remaining an object for other, as yet unabandoned afflictions. Thus, after the factors abandoned through seeing suffering are eliminated, universally ranging afflictions belonging to seeing origination can still take that abandoned class as their object. Similarly, during cultivation, an earlier eliminated grade remains a possible object for the grades of affliction that have not yet been eliminated.

Liberation is therefore not merely the removal of a factor. It is the progressive dissolution of the relations through which remaining afflictions can still organize themselves around what has already been abandoned.

## Course of Argument

### 1. Vasubandhu formulates an implication test

The Bhāṣya asks whether two relations are equivalent:

```text
prahīṇa
    abandoned

visaṃyukta
    disconnected
```

Two directions must be tested:

```text
visaṃyukta → prahīṇa ?
prahīṇa → visaṃyukta ?
```

The answer is asymmetrical.

### 2. Complete disconnection entails abandonment

```text
visaṃyukta
    →
prahīṇa
```

Wherever one is genuinely disconnected, the corresponding object has been abandoned.

### 3. Abandonment does not entail complete disconnection

```text
prahīṇa
    ↛
visaṃyukta
```

This is the point demonstrated by the verse.

### 4. Path of seeing example

The sequence is exact:

```text
duḥkhajñāna arisen
samudayajñāna not yet arisen
```

At this point:

```text
duḥkhadarśanaprahātavya class
    = already abandoned
```

but the practitioner remains connected with it through:

```text
samudayadarśanaprahātavya sarvaga kleśas
    which take that abandoned class as object
```

The abandoned class is no longer the active affliction. It survives only as an object-support for remaining affliction.

### 5. Path of cultivation example

The cultivation-class is divided into nine grades (`nava prakārāḥ`). If an earlier grade has been eliminated:

```text
previous grade
    = prahīṇa
```

remaining afflictions can nevertheless still take it as object:

```text
remaining kleśas
    tadālambana
    → continuing saṃyoga
```

### 6. Transition to the condensed object matrix

Vasubandhu explicitly says that a case-by-case statement of:

```text
which anuśayas
lie latent
with respect to which objects
```

would become excessively long.

Hence he introduces a `piṇḍavibhāṣā`, a condensed systematic exposition. This prepares VAK 5.29 and following.

## Voice Identification

**Voice: Vasubandhu** — formulates the equivalence problem between abandonment and disconnection and gives the asymmetric answer.

**Voice: Abhidharma analytical framework** — the classification by seeing suffering, seeing origination, and nine cultivation grades supplies the doctrinal machinery of the examples.

No significant speaker ambiguity occurs in this unit.

## New Technical Terms

- **visaṃyukta** — disconnected, released from a given object-relation.
  - **status:** important Bhāṣya-level relational determination here.
  - **function:** distinguishes complete disconnection from mere abandonment.

- **prahīṇa** — abandoned, eliminated.
  - **status:** previously encountered.
  - **function:** marks successful elimination of a factor but not necessarily every residual relation to it.

- **tadālambana** — having that as object-support.
  - **status:** productive compound using established `ālambana` vocabulary.
  - **function:** explains how an abandoned class can still participate in bondage without itself remaining an active affliction.

- **piṇḍavibhāṣā** — condensed or aggregate exposition.
  - **status:** Bhāṣya methodological term.
  - **function:** introduces the compressed object/anuśaya matrix beginning with VAK 5.29.

- **prakāra** — grade, mode, subdivision.
  - **status:** previously encountered but technically sharpened here.
  - **function:** names the nine graded levels within afflictions abandoned through cultivation.

## Doctrinal Determination

The decisive distinction is:

```text
abandonment of X
    ≠
complete absence of every relation to X
```

More precisely:

```text
X is abandoned as an afflictive possession

while

Y remains unabandoned
and takes X as its object

therefore

the practitioner remains connected with X through Y
```

This avoids a serious misunderstanding. The abandoned dharma itself does **not** have to remain causally operative. The continued bondage is generated by the still-present affliction whose object is the already-abandoned class or grade.

Thus:

```text
persistence of object-reference
    ≠
persistence of the abandoned affliction itself
```

This is especially important after 5.27. Vasubandhu does not need to reintroduce a substantially existing past dharma in order to explain residual relation. The present relational structure of the continuum is enough.

## Effect on Kārikā Translation

**Clarification only.**

The first-pass translation is sound, but the Bhāṣya fixes the logical asymmetry explicitly:

```text
visaṃyukta → prahīṇa
prahīṇa ↛ visaṃyukta
```

It also clarifies that the continuing connection is mediated by **other unabandoned afflictions taking the abandoned factor as object**, not by continued efficacy of the abandoned factor itself.

## Logical Determination

This is a clean case of non-convertible implication.

Let:

```text
P(x) = x is abandoned
V(x) = practitioner is disconnected from x
```

Then:

```text
V(x) → P(x)

but

P(x) ↛ V(x)
```

The counterexample has a relational form:

```text
P(x)
¬P(y)
y hasObject x
    →
¬V(x)
```

So the failure of conversion is generated by a mediating relation.

The important structure is therefore not merely:

```text
presence / absence
```

but:

```text
node-status
plus
relation-status
```

A determination can be negated at the level of possession while remaining implicated at the level of object-relation.

## Light Organon Contact Point

This is a strong architectural result, but it should remain subordinate to the Bhāṣya's practical logic.

A system cannot infer complete release from the deletion of a state:

```text
StateRemoved
    ↛
AllRelationsToStateRemoved
```

The stronger condition is:

```text
state eliminated
+
no remaining active determination takes it as object/support
    →
complete disconnection
```

This is closer to dependency cleanup than simple deletion. In practical reasoning, liberation is relationally complete only when the remaining system can no longer regenerate bondage around the abandoned determination.

## Bhāṣya Pass Result

VAK 5.28 returns from the temporal ontology debate to the practical question that generated it. The result is highly precise:

```text
visaṃyoga is stronger than prahāṇa
```

An affliction can be abandoned while the practitioner remains connected to it through other, still-unabandoned afflictions that take it as their object. This applies both to the sequential knowledges of the path of seeing and to the nine graded abandonments of cultivation.

The Bhāṣya therefore models liberation as progressive restructuring of an afflictive relation-network, not merely subtraction of isolated mental items. It then introduces a `piṇḍavibhāṣā` because enumerating every anuśaya/object relation individually would be unwieldy; this directly prepares VAK 5.29.
