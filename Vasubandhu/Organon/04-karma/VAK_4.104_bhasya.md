# VAK 4.104 Bhāṣya — Intention, Preparation, and the Path

## 1. Kārikā Anchor

```iast
buddhe na tāḍanecchasya prahārān nordhvam arhati /
nānantaryaprayuktasya vairāgyaphalasaṃbhavaḥ // 4.104 //
```

> Intention merely to strike in the Buddha case does not produce the
> immediate-result classification; nor does an earlier action against a
> non-arhat become an arhat-killing action if the person becomes an arhat
> only afterward. For one engaged in an immediate-result action, the
> possibility of dispassion or a Path fruit does not arise.

## 3. Continuous Scientific English Rendering

Does causing blood to flow from the Tathāgata with a hostile mind
necessarily receive the immediate-result classification? It does when
there is an intention to kill.

In the Buddha case, not for one whose intention is only to strike. If
someone intends only to strike, the immediate-result classification does
not follow. If someone acts against a person who is not an arhat, and
that person becomes an arhat afterward, the classification still does
not follow. The verse says, “nor after the blow does [the person] become
an arhat”; the point is that the action was not directed at an arhat.

If someone has undertaken preparation for an immediate-result action and
has not reversed that preparation, can dispassion or a Path fruit arise?
For one engaged in an immediate-result action, the possibility of
dispassion or a Path fruit does not arise.

The following prose contrasts another action-course: when the noble Path
arises, that action-course does not arise again, because the support is
wholly opposed to it. The witness's compound in this last sentence is
uncertain; this rendering preserves only the secure contrast stated by
the remainder of the sentence.

## 4. Two Limits on Retrospective Classification

The first case distinguishes intention to kill from intention only to
strike in the Buddha context. The second distinguishes the victim's
status when the action is directed from a later attainment: a person who
was not an arhat at that time does not retroactively become the field of
the earlier action merely by attaining arhatship afterward.

These cases concern the relation among intention, operative preparation,
and the qualified field. The physical result alone does not supply the
classification.

## 5. Preparation, Dispassion, and the Path

The question explicitly conditions its claim on the preparation remaining
unreversed (`tasminn avyāvartite`). The verse states that for one engaged
in immediate-result action there is no possibility of dispassion or a
Path fruit; it does not say that anyone who once began such a course can
never abandon it.

The final prose adds the converse practical direction: when the noble
Path arises after an ordinary action-course has been prepared, that
course does not arise again because the support has become wholly opposed
to it. This explanation is attributed to the Bhāṣya; the witness's
compound `anyakarmaphalapathaprayogaṃ` remains unresolved.

## 6. Interpretation

This unit sets out a temporal and practical nexus: the target's status
when preparation is directed, whether that preparation remains
unreversed, and whether the noble Path arises afterward all affect the
course's classification or completion. It does not treat later status
as a retroactive change to the earlier action, nor does it treat the
initial undertaking as irreversible when the question explicitly says
it remains unreversed.

The source terms are *icchā* and *abhiprāya* for desire or intention.
It does not name *cetanā*, so the passage's intention distinctions are
preserved without identifying them with the technical term for
volition.
