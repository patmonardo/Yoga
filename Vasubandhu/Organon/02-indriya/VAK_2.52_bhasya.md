# VAK_2.52 Bhāṣya — Homogeneous Cause

## 1. Kārikā Anchor

> sabhāgahetuḥ sadṛśāḥ svanikāyabhuvo 'grajāḥ /
>
> anyo 'nyaṃ navabhūmis tu mārgaḥ samaviśiṣṭayoḥ // 2.52 //

> A homogeneous cause is similar, of its own class and level, and
> prior-born. The Path crosses the nine levels as cause for the equal or
> the superior.

## 2. Continuous Sanskrit Witness

> sabhāgahetuḥ katamaḥ /
> sabhāgahetuḥ sadṛśāḥ /
> sadṛśā dharmāḥ sadṛśānāṃ dharmāṇāṃ sabhāgahetus tadyathā kuśalāḥ pañca skandhāḥ kuśalānām anyonyaṃ /
> svanikāyabhuvaḥ /
> svo nikāyo bhūś caiṣāṃ ta ime svanikāyabhuvaḥ /
> anyo 'nyaṃ navabhūmis tu mārgaḥ samaviśiṣṭayoḥ // 2.52 //

The unit is printed 85.08–87.20 in `Vasubandhu/Sources/kosabhasya.txt`. Defects remain. Not a collation.

## 3. Continuous Conventional Translation

Similar of similar, within the order stated. Own class and own level. Prior-born, of later, arisen or not. Future is not this cause. Never-not-a-cause is the other three. State, not substance. The Path is adventitious, not appropriated, and crosses its nine levels toward the equal or the superior. Faculties and accumulation, not height.

## 4. Interpretation

Homogeneous is similar, own class and level, prior-born. Future is not. Path crosses nine levels, equal or superior only. Not same-class. State, not substance.
