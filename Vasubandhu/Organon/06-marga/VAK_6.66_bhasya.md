# VAK_6.66 Bhāṣya — Four Courses; Same Path, Another Name

After 6.65's four operations: how the road is walked. Ease is not speed.

## 1. Kārikā Anchor

> dhyāneṣu mārgaḥ pratipat sukhā duḥkhānyabhūmiṣu |
> dhandhābhijñā mṛdumateḥ kṣiprābhijñetarasya tu || 6.66 ||

Literal (from the kārikā study):

> In the dhyānas the Path is an easy course; in the other grounds it is difficult.
> For one of mild faculty it has slow realization, but for the other it has quick
> realization.

Kārikā study: [`VAK_6.66.md`](./VAK_6.66.md). Next: 6.67.

## 2. Continuous Sanskrit Witness

> mārga eva punaḥ pratipad ity ukto nirvāṇapratipādanāt / catasraḥ pratipadaḥ /
> caturdhyāneṣu mārgaḥ sukhā pratipat / aṅgaparigrahāt śamathavipaśyanāsamatābhyām ayatnavāhitvāt /
> anyāsv anāgamyadhyānāntarārūpyabhūmiṣu … yatnavāhitvāt /
> śamathanyūne hy anāgamyadhyānāntare vipaśyanānyūnā ārūpyā iti /
> mṛdvindriyasya … dhandhābhijñā / tīkṣṇendriyasya kṣiprābhijñā /
> punar apy eṣa mārgo bodhipakṣyākhyāṃ labhate /

**Witness.** Pradhan 382|07–20. Voice: Vasubandhu. 6.67 at 382|21. E-text *dhanyābhijñā*; prose is *dhandhābhijñā*.

## 3. Continuous Conventional Translation

> The Path itself is also called *pratipad*, because it conducts to nirvāṇa. Four
> courses: difficult and slow; difficult and quick; easy and slow; easy and quick.
>
> In the four dhyānas the Path is an easy course: the limbs are held, calm and
> insight sit even, it runs without strain. In the other grounds — *anāgamya*,
> *dhyānāntara*, formless — it is difficult: limbs not fully held, calm or insight
> thin, it runs by effort. Calm is thin in *anāgamya* and *dhyānāntara*. Insight is
> thin in the formless.
>
> Each course is again two. Mild faculty: slow realization, easy or hard. Sharp
> faculty: quick. Again this same Path takes the name *bodhipakṣya*.

## 4. Movement of the Commentary

```text
same Mārga as pratipad
ease ← ground (balance of śamatha / vipaśyanā)
speed ← faculty
easy+slow and hard+quick both stand
then the same Path = bodhipakṣya
```

## 6. The Bhāṣya's Decisions for the Kārikā

- *sukha* here is structural ease, not a mood;
- *dhandha* not *dhanya*;
- *bodhipakṣya* is this Path renamed, not a second road.
