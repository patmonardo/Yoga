# Dhātunirdeśa Kārikā

Sequential reading edition of the forty-eight Dhātunirdeśa kārikā studies,
VAK 1.01–1.48.

Canonical editable sources are `Organon/01-dhatu/VAK_1.01.md` through
`VAK_1.48.md`. This edition compiles those studies in numerical order;
Bhāṣya studies are not build inputs.

Run `./build.sh` from this directory. Requires Pandoc, XeLaTeX, and the
FreeSerif, Lato, and FreeMono fonts.

Output: `Organon-Kosa-Dhatu-Karika.pdf`
