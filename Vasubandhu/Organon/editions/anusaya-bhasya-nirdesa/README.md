# Anuśayanirdeśa Bhāṣya

Complete chapter reading edition: 70 consecutive Bhāṣya studies, VAK
5.01–5.70. The individual studies remain provisional and retain their
textual and interpretive review qualifications.

The canonical editable sources are `Organon/05-anusaya/VAK_5.01_bhasya.md`
through `VAK_5.70_bhasya.md`. This derived PDF collects their Sanskrit,
continuous conventional translations, and focused studies. Kārikā-only
studies are not build inputs.

Run `./build.sh` from this directory. Requires Pandoc, XeLaTeX, and the
FreeSerif, Lato, and FreeMono fonts.

Output: `Organon-Kosa-Anusaya-Bhasya.pdf`

The earlier `Organon-Kosa-Anusaya-Bhasya-Part-One.pdf` remains a separate
partial snapshot covering VAK 5.01–5.58.
