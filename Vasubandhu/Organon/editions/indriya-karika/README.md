# Indriyanirdeśa Kārikā

Sequential reading edition of the seventy-three Indriyanirdeśa kārikā
studies, VAK 2.01–2.73.

Canonical editable sources are `Organon/02-indriya/VAK_2.01.md` through
`VAK_2.73.md`. This edition compiles those studies in numerical order;
Bhāṣya studies are not build inputs.

This directory contains its own print header and page-break filter.

Run `./build.sh` from this directory. Requires Pandoc, XeLaTeX, and the
FreeSerif, Lato, and FreeMono fonts.

Output: `Organon-Kosa-Indriya-Karika.pdf`
