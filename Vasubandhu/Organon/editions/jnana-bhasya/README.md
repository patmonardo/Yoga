# Jñānanirdeśa Bhāṣya

Continuous reading edition of the fifty-six Jñānanirdeśa Bhāṣya studies,
VAK 7.01–7.56.

Canonical editable sources are `Organon/07-jnana/VAK_7.01_bhasya.md` through
`VAK_7.56_bhasya.md`. This edition compiles those studies in numerical order;
kārikā-only studies are not build inputs.

This directory contains its own print header and page-break filter.

Run `./build.sh` from this directory. Requires Pandoc, XeLaTeX, and the
FreeSerif, Lato, and FreeMono fonts.

Output: `Organon-Kosa-Jnana-Bhasya.pdf`
