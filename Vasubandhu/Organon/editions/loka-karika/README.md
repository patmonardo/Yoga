# Lokanirdeśa Book Edition

This directory contains the print-oriented PDF edition generated from the
all 102 studies in `Organon/03-loka`, VAK 3.01–3.102.

The study files remain the canonical editable sources. The PDF is a derived
reading artifact. Every kārikā begins on a new page, while long individual
studies may continue across as many pages as required.

This provisional edition records the completed Lokanirdeśa study sequence,
VAK 3.01–3.102.

Build requirements:

- Pandoc
- XeLaTeX
- FreeSerif, Lato, and FreeMono fonts

Run `./build.sh` from this directory to rebuild the PDF.
