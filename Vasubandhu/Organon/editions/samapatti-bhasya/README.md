# Samāpattinirdeśa Bhāṣya

Continuous reading edition of the forty-three Samāpattinirdeśa Bhāṣya
studies, VAK 8.01–8.43.

Canonical editable sources are `Organon/08-samapatti/VAK_8.01_bhasya.md`
through `VAK_8.43_bhasya.md`. This edition compiles those studies in
numerical order; kārikā-only studies are not build inputs.

This directory contains its own print header and page-break filter.

Run `./build.sh` from this directory. Requires Pandoc, XeLaTeX, and the
FreeSerif, Lato, and FreeMono fonts.

Output: `Organon-Kosa-Samapatti-Bhasya.pdf`
