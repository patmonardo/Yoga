# Dhātunirdeśa Bhāṣya

Sequential reading edition of the forty-eight Dhātunirdeśa Bhāṣya studies,
VAK 1.01–1.48.

Canonical editable sources are `Organon/01-dhatu/VAK_1.01_bhasya.md` through
`VAK_1.48_bhasya.md`. This edition compiles those studies in numerical order;
kārikā-only studies are not build inputs.

Run `./build.sh` from this directory. Requires Pandoc, XeLaTeX, and the
FreeSerif, Lato, and FreeMono fonts.

Output: `Organon-Kosa-Dhatu-Bhasya.pdf`
