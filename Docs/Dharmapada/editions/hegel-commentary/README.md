# Dharmapāda: Hegel Commentary Edition

This directory contains the print-oriented PDF edition generated from the
thirty completed Hegel reports in `Docs/Dharmapada`: Yoga Sūtra IV.2–IV.25 and
IV.29–IV.34.

The Markdown reports remain the canonical editable sources. The PDF is a
derived reading artifact. Each sūtra report begins on a new page, while a
report may continue across as many pages as required.

Yoga Sūtra IV.1 is intentionally outside this project's Dharmapāda sequence.
Hegel reports for IV.26–IV.28 have not yet been produced and are therefore not
represented in this edition. The separate Fichte-oriented
`ys-iv-8-10-synthesis.md` is also excluded.

The edition identifies the larger project construction as the
**Prajñā–Dharma Abhidharma**. This project-level identity does not erase the
distinctions among the Yoga source, its commentarial witnesses, Hegel's text,
and the Organon reconstruction maintained within each report.
