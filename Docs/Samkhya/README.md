# Organon Sāṃkhya Reports

This directory bootstraps the Sāṃkhya component of the [Organon Report
Framework](../organon-method-in-practice.md). It is a working source and
inference register for a future study of the *Sāṃkhya Kārikā* and related
commentaries. It does not claim a complete edition or a comprehensive
Sāṃkhya interpretation.

## Current witnesses and limits

- [Reference/Samkhya.txt](../../Reference/Samkhya.txt) supplies the local
  Devanāgarī Kārikā sequence. It contains embedded editorial numerals and
  has no identified historical commentary in this directory.
- The [Kārikā guide notebook](../../Reference/samkhya-karikas-guide.ipynb)
  is a working aid, not an independent textual witness.
- Later Sāṃkhya commentaries and historical claims about the origin of
  practices require named passages before they enter the source layer.

## Reports

1. [Initial distinctions: Buddhi, *aiśvarya*, and non-obstruction](sk-23-45-buddhi-aishvarya-report.md).

The first report records a small, testable result needed before expanding
Yoga I.29–33. Future reports can follow the Kārikā sequence, including the
proofs, the fivefold Object, the instrument, and the path of knowing.

## Editorial rule

Each report should give the source passage, a close determination, the
Organon proposal, a comparison only where evidence supports it, and a
counter-reading or unresolved question. Do not revise the Yoga studies on
the strength of an unlocated Sāṃkhya passage.
